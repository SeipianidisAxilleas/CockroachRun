Руководство пользователя

Данная игра "Тараканьи Бега"является увлекательной игрой для пользователей всех возрастов!

Цель игры заключается в том чтобы один из тараканов добежал до финиша первым.

Игровое поле состоит из панели в которой находятся два таракана.

Игроки выбирают своего таракана записывая его имя в поле для имени.
